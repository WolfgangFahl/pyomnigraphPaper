# federated

Results of the evaluation task
[pyomnigraphPaper #24](https://github.com/WolfgangFahl/pyomnigraphPaper/issues/24):
the three-leg federated queries per use case and the
remote-remote-remote versus local-local-local comparison across backend
combinations. Benchmark timings are a side effect of these runs and land
here as CSV alongside the query definitions.
